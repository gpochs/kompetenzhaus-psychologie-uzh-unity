# Original procedural audio

Generated locally by `tools/generate-audio.mjs`: eight brief feedback/footstep cues and one optional 16-second looping ambience. No recordings, downloaded samples, external model calls or billable services are used. The script is deterministic and `--check` compares every generated byte.

All WAV files are mono, 44.1 kHz, 16-bit PCM. `manifest.json` records durations, peak/RMS levels, hashes and descriptions.

| Clip | Use |
| --- | --- |
| `ui-hover.wav` | Optional quiet pointer hover; disabled by default. |
| `ui-select.wav` | Selecting a module or opening a panel. |
| `footstep-a.wav`, `footstep-b.wav` | Alternate on actual avatar steps. |
| `build-place.wav` | Landing a building component. |
| `quest-complete.wav` | Completion of a learning task. |
| `milestone.wav` | Infrequent, meaningful study milestones. |
| `ui-unavailable.wav` | Soft feedback for an unavailable action. |
| `courtyard-ambience.wav` | Optional subtle tonal bed; loop at low volume. |

Start sound only after the player enables it, respect the master toggle and provide visible equivalents. Fade ambience in/out over roughly half a second; a playback gain around 0.35 is a starting point for in-game balancing. The tonal ambience uses periodic components to join continuously at the loop boundary. These are designed sound cues, not recordings of a real courtyard.
